# snipperting - Snippets tool for Windows
Save text snippets and easily access them from SysTray icon.
Windows application, accessed via menu from SysTray.
App runs a little HTTP server listening on on 127.0.0.1 port 45690..45699.
Web server is used for basic web apps, the editor, the preferences window, etc. things we might find useful.
Written in Go, using Justfile for command runner, ships with installer for ease of use.
Installs somewhere local for user, for example some %LOCALDATA% sub-folder.
Application keeps basic config in JSON file, next to installed executable. 
Config JSON is generated by application on first startup, it's not shipped.

## SysTray menu
The tray icon uses a **native Windows menu** (left-click and right-click). It must not open a web window for the snippet list.
SysTray menu shows list of snippets, and sub-categories of snippets.
When a snippet is clicked in the menu, it fires its configured action.
Action can be configured per snippet (editor / Preferences Bulk Edit).
Available actions are:
- Clipboard - place snippet content in clipboard so it can be pasted
- Inject - inject the snippet at cursor position, wherever it might be!
- Enable/Disable - Gray out the snippet in the menu, it will be listed but can't be clicked (set in Bulk Edit)

Subfolder opens a native submenu to the side.
Footer items under a separator:
- Edit
- Preferences
- Help
- About
- Exit

Edit, Preferences, Help, and About open WebView2 windows. The snippet list itself is native only.

## Data folder
Snippets data is stored in plain text files, markdown, with .md file extension.
Location is stored in config file, default snipperting data folder is `~/.snipperting`
Each file is a snippet, and should be listed as one entry in the menu.
Data dir can have sub-folders, these will be shown as categories, sub-menus, in the snipperting systray menu.

## File format
Snippets can have a header, that won't be included when injecting or copying info clipboard.
Example: `demo-snippet.md`

```md
----
label: Demo Snippet (label will be used instead of filename in menu, if it's configured).
about: Description of the snippet displayed when hovering an item in the menu, kinda like alt-text.
action: inject/clipboard - action that fires when clicked.
state: enable/disable, on/off, true/false. a bool, can be updated by clicking menu button.
hidden: true/false - bool, hides item from menu.
----
# Snippet example title
Wow a snippet body, so fancy!
```

## Editor
The editor is built using Monaco JS editor in an web window, not the browser. 
Monaco is full on Markdown mode and supports everything Markdown, tables, etc.
Editor must have a file browser that browses the data dir and we are going to edit files in the data dir.
When editor launched from main menu, it opens into the file browser and user can select which file to edit.

## Preferences
Preferences window is where we configure Snipperting.
Things to configure, starting out:
- Data directory: Location.
- Theme: System, Light, Dark.
- Bulk Edit

### Data directory: 
Where all snippets are stored, default `~/.snipperting`

### Theme:
This is the theme for all the webapp pages we're going to make.
Default theme is System, it will follow system for dark/light.
Dark or Light theme can be selected to override, obviously.

### Bulk Edit preferences tab:
Change things in bulk over multiple snippets. 
Snippet settings such as state, action, hidden. 
This will update the settings in each and every snippet file.
Looks like a list, and every row has:
- left aligned: filename, label
- right aligned: toggle buttons for
  - action: inject/clipboard
  - state: on/off
  - hidden: on/off
Subfolders are displayed folded, can be unfolded to view items, are indented in display.
